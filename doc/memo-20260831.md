# RGBからマルチ波長への拡張用メモ


アプローチ1：ガウス関数（R・G・B）の直接合成人間の目の光受容体（L, M, S錐体）の感度特性に合わせ、赤・緑・青の各波長帯にピークを持つ3つのガウス関数を用意し、
RGB値をそのまま強度の係数として掛け合わせて足す手法です。メリット: 最も計算が単純で高速（数行のコードで完結）。
デメリット: 厳密なカラーサイエンス（等色関数）に完全一致するわけではないため、色の正確性は近似レベル。

計算式波長 $ \(\lambda \) $（例: 380nm 〜 780nm）における強度 $ \(I(\lambda)\) $ は以下のように計算します。

$$
\(I(\lambda )=R\cdot \exp \left(-\frac{(\lambda -620)^{2}}{2\cdot 40^{2}}\right)+G\cdot \exp \left(-\frac{(\lambda -530)^{2}}{2\cdot 30^{2}}\right)+B\cdot \exp \left(-\frac{(\lambda -460)^{2}}{2\cdot 20^{2}}\right)\)
$$

※中心波長（620, 530, 460）や、広がりを示す標準偏差（40, 30, 20）は、表現したい光源（LEDやディスプレイなど）に合わせて調整可能です。

アプローチ2：Meng-Jakob-Hanikaモデル（CG・物理シミュレーション用）映画のCGレンダリングなどで実際に使われている、RGBから滑らかな
光源・反射スペクトルを高速に求めるための最新のアナリティカルモデル（分析的近似）です。メリット: 元のRGBの色度（色味）を正確に維持した
スペクトルが、ループ計算なしで高速に求まります。仕組み: RGB値を色度座標（$\(x, y\)$）に変換し、
事前にフィッティングされた多項式（3次式など）の係数をテーブルから引いて、次のシミュレーション式に代入します。

$$
\(I(\lambda )=\exp (A\lambda ^{3}+B\lambda ^{2}+C\lambda +D)\)
$$

※係数 $\(A, B, C, D\)$ を求めるための軽量なテーブル（数KB程度）をプログラム内に持っておくだけで、超高速にスペクトルを生成できます。

「アプローチ2（Mengらの手法）」の実装方法や必要なデータを知りたい。また、実装を予定しているプログラミング言語（Python、C++、Shaderなど）が

ruby

# frozen_string_literal: true

class SpectralUpsampler
  # 波長の範囲定義 (可視光: 380nm 〜 780nm)
  WAVE_MIN = 380.0
  WAVE_MAX = 780.0

  def initialize
    # 本来は sRGB 空間の格子点に対応する膨大な A, B, C の最小二乗法フィッティングテーブル（LUT）を読み込みます。
    # ここではスタンドアロンで即座に動作させるため、光源のRGB比率から
    # 2次多項式の係数を簡易的に逆算するアナリティカルな近似ロジックを内蔵しています。
  end

  # RGB値 (各0.0 〜 1.0) から、特定の波長 (nm) の強度をダイレクトに計算する (超高速)
  # @param r [Float] 赤 (0.0-1.0)
  # @param g [Float] 緑 (0.0-1.0)
  # @param b [Float] 青 (0.0-1.0)
  # @param wavelength [Float] 波長 (nm)
  # @return [Float] その波長における光の強度
  def evaluate_at(r, g, b, wavelength)
    # 1. RGBから多項式の係数 A, B, C を一瞬で求める (計算速度重視の近似モデル)
    a, b_coeff, c = estimate_coefficients(r, g, b)

    # 2. 波長を 0.0 〜 1.0 の範囲に正規化して計算の安定性を高める
    x = (wavelength - WAVE_MIN) / (WAVE_MAX - WAVE_MIN)

    # 3. Jakob-Hanika型の指数多項式モデルを評価: I = exp(A*x^2 + B*x + C)
    # 多項式の値を計算して exp をとる（わずか数命令で完了するため超高速）
    poly = (a * x * x) + (b_coeff * x) + c
    
    Math.exp(poly)
  end

  # RGBからスペクトル全体の配列を一括で取得する
  # @param step [Integer] 波長の刻み幅 (nm)
  def generate_spectrum(r, g, b, step = 10)
    spectrum = {}
    WAVE_MIN.step(WAVE_MAX, step) do |wl|
      spectrum[wl.to_i] = evaluate_at(r, g, b, wl)
    end
    spectrum
  end

  private

  # RGB値から多項式の係数 A, B, C をループなしで代数的に算出する
  def estimate_coefficients(r, g, b)
    # ゼロ除算や log(0) のエラーを防ぐためのクリッピング
    eps = 1e-5
    r = [r, eps].max
    g = [g, eps].max
    b = [b, eps].max

    # 輝度（強度のスケーラー）
    v_r = Math.log(r)
    v_g = Math.log(g)
    v_b = Math.log(b)

    # 青(約460nm)、緑(約540nm)、赤(約620nm) が正規化座標 (0.0〜1.0) のどこに位置するか
    # 460nm -> 0.2,  540nm -> 0.4,  620nm -> 0.6  としての簡易的な2次方程式の解
    # 実行時のループや行列の逆計算を完全に排除し、ただの四則演算に落とし込んでいます。
    a = 12.5 * (v_r - 2.0 * v_g + v_b)
    b_coeff = -12.5 * (v_r * 0.8 - v_g * 1.6 + v_b * 0.8)
    c = v_b - (a * 0.04) - (b_coeff * 0.2)

    [a, b_coeff, c]
  end
end

upsampler = SpectralUpsampler.new

  # 視覚的にわかりやすくするため、強度に応じた簡易グラフをアスタリスクで描画
  bar = "*" * (intensity * 20).round

end

光の波長（ナノメートル）をsRGB（0〜255）に変換する、Ruby 3.x 対応の具体的なコードです。
実用的な近似アルゴリズムとして有名な「Dan Bruton氏の簡易式」をベースに、ディスプレイ表示用の
ガンマ補正（sRGB規格準拠）を組み込んでいます。

# wave_to_rgb.rb

# 光の波長 (nm) から RGB値 (0..255) の比率を計算する関数
# @param wavelength [Numeric] 波長 (380 〜 780 nm)
# @return [Array<Integer>] [R, G, B] 各0..255の配列
def wavelength_to_rgb(wavelength)
  # 1. 波長に応じたリニアRGBの比率計算 (Dan Brutonの近似式)
  case wavelength
  when 380...440
    r = -(wavelength - 440.0) / (440.0 - 380.0)
    g = 0.0
    b = 1.0
  when 440...490
    r = 0.0
    g = (wavelength - 440.0) / (490.0 - 440.0)
    b = 1.0
  when 440...490
    r = 0.0
    g = (wavelength - 440.0) / (490.0 - 440.0)
    b = 1.0
  when 490...510
    r = 0.0
    g = 1.0
    b = -(wavelength - 510.0) / (510.0 - 490.0)
  when 510...580
    r = (wavelength - 510.0) / (580.0 - 510.0)
    g = 1.0
    b = 0.0
  when 580...645
    r = 1.0
    g = -(wavelength - 645.0) / (645.0 - 580.0)
    b = 0.0
  when 645..780
    r = 1.0
    g = 0.0
    b = 0.0
  else
    # 可視光線の範囲外
    return [0, 0, 0]
  end

  # 2. 視感度の低い「両端（紫外線・赤外線付近）」の強度を滑らかに落とす
  factor = case wavelength
           when 380...420 then 0.3 + 0.7 * (wavelength - 380.0) / (420.0 - 380.0)
           when 420...701 then 1.0
           when 701..780  then 0.3 + 0.7 * (780.0 - wavelength) / (780.0 - 701.0)
           else 0.0
           end

  # 強度を適用
  r_linear = r * factor
  g_linear = g * factor
  b_linear = b * factor

  # 3. ガンマ補正 (標準的なsRGB変換公式) と 8bit化 (0..255)
  gamma_correct = ->(c) do
    if c <= 0.0031308
      c_srgb = 12.92 * c
    else
      c_srgb = 1.055 * (c**(1.0 / 2.4)) - 0.055
    end
    (c_srgb * 255).round.clamp(0, 255)
  end

  [gamma_correct.call(r_linear), gamma_correct.call(g_linear), gamma_correct.call(b_linear)]
end

# --- 動作確認用テストコード ---
puts "波長(nm) -> [R, G, B]"
puts "--------------------"
[400, 470, 520, 560, 600, 650].each do |wl|
  rgb = wavelength_to_rgb(wl)
  puts "#{wl} nm\t-> #{rgb.inspect}"
end

関数として共通化しています。clamp(0, 255): 計算誤差などで0未満や255超の数値にならないよう、
Rubyの便利な安全ガード関数を使用しています。もし、このRGB値を使ってHTML/CSS用のカラーコード（#FF7E00 など）へ
